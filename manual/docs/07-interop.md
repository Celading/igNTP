# igNTP: interoperability evidence

RFC 4330 is the recorded SNTP reference. Multi-server selection is an application policy, not an implementation of the complete NTP clock-discipline algorithms.

The source tests contain the current local vectors and integration entry points. Re-run the relevant executable at the source revision you consume. An unavailable external peer is unavailable evidence, not a pass. Historical counts, soak results and source-only review do not certify a new build or another platform.

Follow the [verification guide](../skill/verify.md) and retain peer/tool versions, commands, exit status and actual results.
